## Attribution requirements in short

- FAO / World Bank / OWID data: CC BY 4.0 / CC BY — attribution, no
  endorsement implied. The site footer and every visualization carry source
  lines.
- GRFC / IPC: no formal open license; figures reproduced with attribution to
  the Global Network Against Food Crises and the IPC partnership, within
  normal editorial/citation practice for an educational, non-commercial work.
- If you reuse or fork this project, keep the source lines on the page and
  this table intact.
