## Attribution requirements in short

- FAO / World Bank / OWID data: CC BY 4.0 / CC BY — attribution, no
  endorsement implied. The site footer and every visualization carry source
  lines. (The GRFC 2026 report itself is CC BY 4.0 with third-party
  exceptions, per its copyright page.)
- GRFC / IPC figures: reproduced with attribution to the Global Network
  Against Food Crises and the IPC partnership, within normal
  editorial/citation practice for an educational, non-commercial work;
  reuse terms vary by publication and third-party material — check each
  source before republishing.
- If you reuse or fork this project, keep the source lines on the page and
  this table intact.
